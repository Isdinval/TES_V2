# UIA Mapper Prototype 🔍

A specialized Windows GUI automation tool based on `pywinauto` and Microsoft UI Automation (UIA).

## Features
- **Window Picker**: Select any open window using a "crosshair" style picker.
- **UIA Scanning**: Extracts structured information from visible UI elements.
- **Visual Inspection**: Draws bounding boxes on top of a window screenshot.
- **Metadata Viewer**: Inspect Name, AutomationId, ControlType, ClassName, and Patterns.
- **Export**: Save detected elements to JSON.

## Installation
```bash
pip install -r requirements.txt
```

## Usage
```bash
python main.py
```
